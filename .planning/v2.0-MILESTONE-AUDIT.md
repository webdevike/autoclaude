## End-to-End Flows

### Flow 1: iOS Text Message
```
iOS user_text → data channel → LiveKit agent dataReceived
  → routeTextToGateway → POST /api/message → gateway HTTP API
  → orchestrator.handleMessage (SOUL.md injected via buildSystemPrompt)
  → Claude Code execution → onProgress collects tool_use events
  → Response { text, toolsUsed }
  → agent_text_response via data channel → iOS
  → function_tools_executed via data channel → iOS tool cards
```
**Status: COMPLETE** — all steps verified in source

### Flow 2: iOS Voice Tool Result
```
User speaks → OpenAI Realtime → tool execution
  → FunctionToolsExecuted event
  → session.on listener → zipFunctionCallsAndOutputs
  → Structured tool data (name, args, result, isError)
  → publishData function_tools_executed → iOS tool cards
```
**Status: COMPLETE** — all steps verified in source

### Flow 3: CLI Startup Sequence
```
CLI main() → ensureWorkspace() → initRepo() → commitFile(SOUL.md)
  → migrateV1Data() → new AgentOrchestrator()
  → createIntegrations() → gateway.start()
  → startHttpApi({ orchestrator }) → ready
```
**Status: COMPLETE** — all steps verified in source, order verified correct
