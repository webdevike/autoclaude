## Tech Debt

### Phase 4: Autonomy

**Priority: P1 - Production Limitation**

1. **CronScheduler.executeJob() is a stub**
   - Location: `packages/core/src/cron-scheduler.ts:191-199`
   - Impact: Cron jobs are scheduled and trigger at correct times, but the prompt is never sent to the agent
   - Workaround: External `packages/scheduler/src/index.ts` has working execution (used by CLI)
   - Fix: Add orchestrator callback or reference to CronScheduler

2. **Dual scheduler pattern**
   - Core singleton: `packages/core/src/cron-scheduler.ts` (used by autonomy tools)
   - External class: `packages/scheduler/src/index.ts` (used by CLI)
   - Impact: Architectural confusion, potential for divergence
   - Fix: Choose one pattern and deprecate the other

### Phase 2: Integrations

**Priority: P2 - Code Quality**

1. **CLI uses old integration pattern**
   - Location: `packages/cli/src/index.ts:56-68`
   - Impact: Imports `@jarvis/integration-*` packages alongside `@jarvis/extensions/*`
   - Fix: Verify if integration packages are duplicates, remove or document

### Phase 1: Foundation

**Priority: P3 - Minor**

1. **Unused lower-level exports**
   - Functions: `completeLLM()`, `streamLLM()` in `llm.ts`
   - Impact: Exported but superseded by pi-session abstractions
   - Fix: Document as advanced API or remove if truly unused

## Conclusion

**Milestone v1.0 achieves all 22 requirements.** The agent:

- Uses pi-ai for all LLM calls with streaming and cost tracking
- Runs pi-agent-core with TypeBox tool validation
- Delegates coding tasks to pi-coding-agent in tmux
- Integrates Gmail, Linear, Notion, and Exa as extensions
- Persists preferences and injects them into prompts
- Supports on-the-fly mode switching
- Provides self-configuration tools (with cron execution pending)

**Tech debt is non-blocking.** The cron execution stub means autonomy tools for scheduling are present but jobs don't auto-execute. Users can still:
- Add, list, and remove cron jobs (they persist correctly)
- The external scheduler in CLI can execute them if started

**Recommendation:** Accept tech debt and complete milestone. Address cron execution in v1.1.
