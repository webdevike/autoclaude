# Plan 01-03: Fix Empty Message Errors

**Goal:** Prevent "message text is empty" Telegram errors by adding guards for empty response text

**Root Cause:** Gateway and Telegram channel pass empty strings to Telegram API when orchestrator returns empty response (observed as 0 in/0 out tokens from triage).

## Tasks

**File:** `packages/channels/telegram/src/index.ts`
