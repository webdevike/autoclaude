<task type="auto">
  <name>Task 1: Add v1.0 data migration to WorkspaceManager</name>
  <files>packages/core/src/workspace.ts</files>
  <action>
Add a `migrateV1Data()` method to the WorkspaceManager class (or export as standalone function — use method since it needs workspaceDir).

**migrateV1Data(): void** (synchronous, runs at startup):

1. **Check migration marker:** If `workspace/.migrated-from-v1` exists, log `[workspace] v1.0 migration already completed, skipping` and return immediately. This makes it idempotent.

2. **Migrate sessions:** `~/.jarvis/sessions/{userId}/messages.jsonl` -> `workspace/sessions/{userId}/messages.jsonl`
   - Read `~/.jarvis/sessions/` directory. If it doesn't exist, skip.
   - For each userId subdirectory:
     - Create `workspace/sessions/{userId}/` if not exists
     - If `messages.jsonl` exists in old location AND NOT in new location, copy it using `copyFileSync`
     - Log `[workspace] Migrated session log for {userId}`
   - Use `existsSync` checks before every operation. COPY, don't move — old files are backup.

3. **Migrate preferences:** `~/.jarvis/users/{userId}/preferences.json` -> `workspace/preferences/{userId}.json`
   - Read `~/.jarvis/users/` directory. If it doesn't exist, skip.
   - For each userId subdirectory:
     - If `preferences.json` exists in old location AND `{userId}.json` NOT in new location, copy it
     - Log `[workspace] Migrated preferences for {userId}`

4. **Write migration marker:** Write `workspace/.migrated-from-v1` with content:
   ```
   Migrated from v1.0 on {new Date().toISOString()}
   Sessions copied: {count}
   Preferences copied: {count}
   ```

5. **Log summary:** `[workspace] v1.0 migration complete: {N} sessions, {M} preferences`

6. Wrap entire method in try/catch. On error, log `[workspace] v1.0 migration failed (non-fatal): {error}` — never crash the agent over migration failure.

Add necessary import: `copyFileSync` from "node:fs" (add to existing import).

Also export `migrateV1Data` if it's a standalone function, or just keep it as a method on WorkspaceManager.
  </action>
  <verify>
Run `pnpm type-check` from core package. Verify the migration method exists: `grep -n "migrateV1Data" packages/core/src/workspace.ts` returns match.
  </verify>
  <done>
migrateV1Data() copies sessions and preferences from v1.0 locations to workspace, is idempotent (marker file check), copies don't move, and fails gracefully.
  </done>
