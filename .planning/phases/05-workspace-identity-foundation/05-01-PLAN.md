<task type="auto">
  <name>Task 1: Create WorkspaceManager class with SOUL.md loading and workspace initialization</name>
  <files>packages/core/src/workspace.ts</files>
  <action>
Create `packages/core/src/workspace.ts` with a `WorkspaceManager` class. Follow the patterns established in preferences.ts (homedir resolution, existsSync checks, readFileSync with error handling, mkdirSync recursive).

**Constructor:**
- Compute `workspaceDir = resolve(homedir(), ".jarvis", "workspace")`
- Compute paths for SOUL.md, MEMORY.md, and subdirs (memory/, sessions/, preferences/)

**ensureWorkspace():**
- Create workspace directory and all subdirs (memory/, sessions/, preferences/) with `mkdirSync({ recursive: true })`
- If SOUL.md does not exist, write the default SOUL.md template using atomic write (temp file + renameSync)
- If MEMORY.md does not exist, write a placeholder: `# Memory\n\nCurated long-term memory. Updated by agent with user confirmation.\n`
- Log `[workspace] Initialized workspace at {path}` on first creation, `[workspace] Workspace exists at {path}` on subsequent runs

**Default SOUL.md template** (written on first init):
```markdown
# Jarvis Soul

## Who I Am
A personal AI assistant for Ike. Direct, casual, helpful.

## Communication Style
- Be concise unless asked for detail
- Use plain language, avoid corporate speak
- Show work when problem-solving
- Match the user's energy and tone

## Boundaries
- Never write to SOUL.md without explicit user confirmation
- Always ask before destructive operations
- Respect privacy: don't store sensitive data in memory logs

## Continuity Notes
<!-- Add notes here that should persist across sessions -->
```

**loadSoul():**
- Read SOUL.md from workspace. If file doesn't exist, call ensureWorkspace() then read again.
- Enforce character limit: if content.length > 12000, throw Error("SOUL.md too large (X chars, max 12000). Please trim to stay within context budget.")
- If content.length > 6000, log warning: `[workspace] Warning: SOUL.md is ${content.length} chars (recommend < 6000 for context budget)`
- On read error, log warning and return default soul content (never crash the agent)
- Return the content string

**buildSystemPrompt(basePrompt: string): string:**
- Call loadSoul() to get soul content
- Return: `${soul}\n\n---\n\n${basePrompt}`

**getWorkspaceDir(): string** — returns workspace directory path
**getSoulPath(): string** — returns SOUL.md path

**atomicWriteFile(filePath: string, content: string): void** — private utility:
- Ensure parent dir exists
- Write to `${filePath}.tmp`, then renameSync to filePath
- Follow exact pattern from preferences.ts save() method

Export the class. Use `import { existsSync, mkdirSync, readFileSync, writeFileSync, renameSync } from "node:fs"` and `import { resolve } from "node:path"` and `import { homedir } from "node:os"`.

Do NOT import or use WorkspaceGit here — that dependency will be wired externally by the orchestrator or CLI.

**Step 2:** Create `packages/core/src/workspace-git.ts` with a `WorkspaceGit` class.

**Constructor(workspaceDir: string):**
- Store workspaceDir
- Create simple-git instance bound to workspaceDir: `this.git = simpleGit(workspaceDir)`
- Import: `import simpleGit, { type SimpleGit } from "simple-git"`

**async initRepo(): Promise&lt;void&gt;:**
- Check if already a repo: `await this.git.checkIsRepo()`
- If not a repo:
  - `await this.git.init()`
  - Write .gitignore to workspace (atomic write): `sessions/\npreferences/\n*.tmp\n*.backup\n`
  - `await this.git.add(".gitignore")`
  - If SOUL.md exists in workspace, `await this.git.add("SOUL.md")`
  - If MEMORY.md exists in workspace, `await this.git.add("MEMORY.md")`
  - `await this.git.commit("Initial workspace setup")`
  - Log `[workspace-git] Initialized git repo at {workspaceDir}`
- If already a repo, log `[workspace-git] Git repo exists at {workspaceDir}`
- Wrap entire method in try/catch, on failure log warning: `[workspace-git] Git init failed (non-fatal): {error}` — never throw

**async commitFile(file: string, message?: string): Promise&lt;void&gt;:**
- `await this.git.add(file)`
- `const timestamp = new Date().toISOString()`
- `const commitMsg = message || \`Update ${file} - ${timestamp}\``
- `await this.git.commit(commitMsg)`
- Log `[workspace-git] Committed ${file}: ${commitMsg}`
- Wrap in try/catch, on failure log warning — never throw. Git failures must not block agent operations.

**async getDiff(file: string): Promise&lt;string&gt;:**
- Return `await this.git.diff([file])`
- On error, return empty string

**async getLog(file: string, maxCount = 10): Promise&lt;Array&lt;{ hash: string; date: string; message: string }&gt;&gt;:**
- `const log = await this.git.log({ file, maxCount })`
- Return mapped entries: `log.all.map(e => ({ hash: e.hash, date: e.date, message: e.message }))`
- On error, return empty array

Export the class.
