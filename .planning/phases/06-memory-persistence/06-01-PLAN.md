<task type="auto">
  <name>Task 2: Create memory-tools.ts with memoryAppend and memoryLog</name>
  <files>packages/core/src/tools/memory-tools.ts, packages/core/src/index.ts</files>
  <action>
Create `packages/core/src/tools/memory-tools.ts` with two exported async functions:

**1. `memoryAppend(fact: string, category?: string): Promise<string>`**

Appends a curated fact to MEMORY.md with timestamp:
- Instantiate `WorkspaceManager` and `WorkspaceGit(workspace.getWorkspaceDir())`
- Read existing MEMORY.md content from `workspace.getMemoryPath()` using `readFileSync` (if file exists, else empty string)
- Build entry: `\n## ${new Date().toISOString()}${category ? ` [${category}]` : ""}\n\n${fact}\n`
- Write new content (existing + entry) via `workspace.atomicWriteFile(memoryPath, newContent)`
- Git commit via `workspaceGit.commitFile("MEMORY.md", \`memory: ${fact.slice(0, 50)}\`)` — best-effort, do NOT await or catch (WorkspaceGit already handles errors internally)
- Return string: `Fact saved to MEMORY.md (${Buffer.byteLength(entry)} bytes)`

**2. `memoryLog(note: string): Promise<string>`**

Writes a timestamped note to today's daily log:
- Instantiate `WorkspaceManager`
- Compute today's date: `new Date().toISOString().split("T")[0]` (yields "YYYY-MM-DD")
- Build daily log path: `resolve(workspace.getMemoryDir(), \`${today}.md\`)`
- Read existing content (if file exists), else initialize with `# Daily Log: ${today}\n\n`
- Append entry: `## ${new Date().toISOString()}\n\n${note}\n\n`
- Write via `workspace.atomicWriteFile(dailyLogPath, newContent)`
- No git commit for daily logs (too noisy per research — git tracks MEMORY.md only)
- Return string: `Note logged to ${today}.md (${Buffer.byteLength(entry)} bytes)`

**Imports needed:**
- `WorkspaceManager` from `"../workspace.js"`
- `WorkspaceGit` from `"../workspace-git.js"`
- `existsSync`, `readFileSync` from `"node:fs"`
- `resolve` from `"node:path"`

**Export from index.ts:**
Add `export { memoryAppend, memoryLog } from "./tools/memory-tools.js";` to packages/core/src/index.ts.

**No confirmation flow** for memory tools — per research decision (unlike preferences which use confirmation). Memory writes are tool output, user reviews via git diff if needed.
