<task type="auto">
  <name>Task 1: Create core tools module</name>
  <files>packages/core/src/tools/core-tools.ts, packages/core/src/types.ts</files>
  <action>
Create `packages/core/src/tools/core-tools.ts` with the 4 core tools using pi-mono's tool format:

1. **Read tool** - Read file contents with optional line limits
   - Parameters: `file_path` (string, required), `offset` (number, optional), `limit` (number, optional)
   - Uses fs.readFileSync with line number prefixes (like cat -n)
   - Truncate output to 50KB or 2000 lines using truncateHead pattern from research

2. **Write tool** - Write content to a file
   - Parameters: `file_path` (string, required), `content` (string, required)
   - Creates parent directories if needed (mkdirSync recursive)
   - Returns success message with file path

3. **Edit tool** - String replacement in files
   - Parameters: `file_path` (string, required), `old_string` (string, required), `new_string` (string, required), `replace_all` (boolean, optional)
   - Validates old_string exists and is unique (unless replace_all)
   - Returns success message with replacement count

4. **Bash tool** - Execute shell commands
   - Parameters: `command` (string, required), `timeout` (number, optional, default 120000)
   - Uses child_process.execSync with timeout
   - Capture stdout/stderr, truncate if too long
   - Returns combined output

Use TypeBox for schemas as shown in research:
```typescript
import { Type } from "@sinclair/typebox";

parameters: Type.Object({
  file_path: Type.String({ description: "Absolute path to the file" }),
  // ...
})
```

Export a `createCoreTools(cwd: string)` function that returns array of tool definitions compatible with pi-agent-core.

Also update `packages/core/src/types.ts` to export `ToolDefinitionPiAi` type if not already present.
