  <action>
After the `session.start()` call and before `ctx.connect()` in the `entry` function, add an event listener on `session` for the `function_tools_executed` event.

Import `voice` namespace is already available (imported at top). Use `AgentSessionEventTypes` enum or the string `"function_tools_executed"` for the event name.

The event handler receives a `FunctionToolsExecutedEvent` with:
- `functionCalls: FunctionCall[]` — each has `.name` (string) and `.args` (JSON string)
- `functionCallOutputs: FunctionCallOutput[]` — each has `.name` (string), `.output` (string), `.callId` (string), `.isError` (boolean)

Use the `zipFunctionCallsAndOutputs` helper (exported from `@livekit/agents` under `voice` namespace) to pair calls with outputs. For each pair, build a tool result object:

```ts
{
  name: functionCall.name,
  arguments: JSON.parse(functionCall.args) (wrapped in try/catch, fallback to raw string),
  result: functionCallOutput.output,
  isError: functionCallOutput.isError,
}
```

Send a data channel message matching the established contract:

```json
{
  "type": "function_tools_executed",
  "tools": [
    {
      "name": "tool_name",
      "arguments": { ... },
      "result": "output string",
      "isError": false
    }
  ]
}
```

This reuses the same `type: "function_tools_executed"` as the text path (Phase 7), but with richer data (arguments and result included). The text path only sends `{ name }` per tool — that's fine, iOS should handle both shapes (tools with and without result).

Use `ctx.room.localParticipant?.publishData()` with `{ reliable: true }` (same pattern as text path). Wrap the entire handler in try/catch to prevent voice agent crashes from data channel publish errors.

Add a console.log: `[livekit-agent] Voice tools forwarded to iOS: {tool_names}` after successful publish.

Place the listener registration AFTER `session.start()` and BEFORE `ctx.connect()` (alongside the existing data channel handler registration area). Add a console.log confirming registration: `[livekit-agent] Voice tool forwarding registered`.
